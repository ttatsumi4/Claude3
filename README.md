# 脱出ゲーム - Ⅰの部屋

難易度★☆☆☆☆ の脱出ゲーム

## ゲーム概要

２つの画面（正面・背面）を切り替えながら、謎を解いて部屋から脱出するゲームです。

## 遊び方

1. `index.html` をブラウザで開く
2. 正面・背面を切り替えながらアイテムを探す
3. 謎を解いてパスワードを見つける
4. カードキーとパスワードで出口のドアを開ける

## ゲーム画面

### 正面
- 出口のドア
- ロック解除パネル

### 背面
- 壁に掛けられた絵
- 書斎テーブル（手提げ金庫、エンピツ、メモ用紙など）
- ロッカー（2つの扉）
- 引き出し（2つ）
- 隠し金庫

## 脱出手順のヒント

1. まずはフリーのロッカーを開けてみましょう
2. 隠し金庫のスイッチは「UDUUU」のパターンです
3. 手提げ金庫のパスワードは壁の絵の裏にあります
4. キーボードのキートップで考えてみてください
5. メモは2つに分かれています
6. 最終的なパスワードは4桁の数字です

### 詳細攻略

1. フリーのロッカーを開ける → **取手** 入手
2. 取手を使って引き出しを開ける → 「**UDUUU**」のメモ発見
3. 隠し金庫のスイッチを「↑↓↑↑↑」に設定してENTER → **カードキー** 入手
4. テーブル上の **ロッカーの鍵** を取る
5. ロッカーの鍵でロッカーを開ける → **モップ** 入手
6. モップで壁の絵を落とす → 絵の裏に暗号「**UUXYEA**」
7. UUXYEA をキーボードのひらがなに変換 → **ななさんいち（731）**
8. 手提げ金庫に「**731**」を入力 → **メモ右半分** 入手
   ```
   2231
   ごさゅうい
   んきち
   ```
9. テーブル上の **エンピツ** を取る
10. **白紙のメモ** をエンピツでこする → 「**613**」が浮かび上がる
11. 引き出しの南京錠に「**613**」を入力 → **メモ左半分** 入手
    ```
    1221
    ぱーど
    すわは
    ```
12. 2つのメモを合体して暗号を解読
    ```
    12212231
    ぱーどごさゅうい
    すわはんきち
    ```

    数字の奇数番目は上段、偶数番目は下段で文字を区切る：
    ```
    ぱ(1) / ーど(2) / ごさ(2) / ゅうい(3)
    すわ(2) / は(1) / んき(2) / ち(1)
    ```

    順番に繋げる：
    ```
    ぱすわーどはごさんきゅういち
    （パスワードは5391）
    ```

13. 正面に移動
14. ロック解除パネルをクリック
15. カードキーを挿入
16. パスワード「**5391**」を入力
17. **脱出成功！**
